AuthGuard
2FA

Aplicación de demostración que protege el acceso con contraseña y códigos TOTP de un solo uso, con sesiones persistentes y base de datos relacional.

Node.jsExpressPrismaSQLiteTOTP

Problema

La contraseña por sí sola deja una cuenta expuesta si se reutiliza o se filtra. El usuario necesita un segundo paso de verificación al iniciar sesión.

Solución implementada

El sistema registra cuentas, almacena contraseñas con hash, genera un QR para una app autenticadora y valida códigos temporales antes de crear la sesión.

Flujo principal

  1. Crear cuenta con correo y contraseña.
  2. Escanear el QR en una app compatible con TOTP.
  3. Confirmar el código de seis dígitos.
  4. Iniciar sesión con contraseña y código temporal.

Componentes

  • Express estructura los endpoints de autenticación.
  • Prisma y SQLite guardan cuentas y estado 2FA.
  • bcryptjs crea hashes de contraseñas.
  • Sesiones en SQLite, cookies httpOnly y límites de intentos.

Descripción para la hoja de vida

Construí una API de autenticación con Node.js y Express, persistencia SQLite mediante Prisma y verificación 2FA basada en TOTP; implementé hash de contraseñas, sesiones y límites de intentos.
